# AI, Explained Softly

A one-page explainer about artificial intelligence: what it is, what it is good for, what can go wrong, and what the future might look like.

- **Live site:** https://erikadoumbova.github.io/ai_project/
- **Built with:** plain HTML, CSS and a little JavaScript, published with GitHub Pages.

## Files

```
ai_project/
├── index.html   # page content and structure
├── styles.css   # pink theme, layout and animations
├── script.js    # scroll reveals, sparkles and small interactions
└── assets/      # images and diagrams
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.
